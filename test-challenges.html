Summary

Challenges tested:

  1. File Upload - Need to send base64 file data
  2. Rich Text (contenteditable) - Standard selectors work, but typing requires focus
  3. Iframe Editor - Need special handling for cross-document content
  4. Custom Select - Need to click trigger, then click option
  5. Modal Dialog - Need to wait for modal to open, find elements inside
  6. Drag and Drop - Requires synthesizing drag events
  7. Keyboard Events - Need dedicated key press command
  8. Auto-complete - Need to type, wait for suggestions, click suggestion
  9. Shadow DOM - Standard selectors can't pierce shadow boundary
  10. Delayed Content - Need waitFor to handle async loading
