What makes Twitter-style uploads tricky:

  • Hidden input: The file input has display: none
  • Button trigger: A visible button calls input.click()
  • Event listeners: The change event must fire to update UI
  • DataTransfer API: Setting input.files requires DataTransfer

The uploadFile action handles all of this by:

  1. Finding the file input (even if hidden)
  2. Creating a File object from base64 data
  3. Using DataTransfer to set input.files
  4. Dispatching change and input events
